Ataques e Ameaças Comuns

🔍 Scanning

O scanning é a técnica usada para identificar portas abertas, serviços e possíveis vulnerabilidades em um sistema. Geralmente é o primeiro passo antes de um ataque mais avançado.

Exemplo: Uso de ferramentas como Nmap para descobrir portas abertas em um servidor.

💉 SQL Injection

O SQL Injection ocorre quando comandos SQL maliciosos são inseridos em campos de entrada. Isso pode permitir acesso não autorizado ao banco de dados.

Exemplo: Inserir ' OR '1'='1 em um campo de login.

🧨 XSS (Cross-Site Scripting)

O XSS permite a execução de scripts maliciosos no navegador da vítima. Ele ocorre quando o sistema não valida corretamente dados de entrada.

Exemplo: Inserir <script>alert('Ataque')</script> em um formulário.

🧠 Engenharia Social

A engenharia social explora o comportamento humano para obter informações confidenciais. O atacante se passa por alguém confiável.

Exemplo: Fingir ser do setor de TI para pedir a senha de um funcionário.

🔑 Força Bruta

Ataques de força bruta tentam diversas combinações de senha até encontrar a correta. Eles exploram senhas fracas ou sistemas sem bloqueio de tentativas.

Exemplo: Testar milhares de senhas automaticamente em um login.

🎣 Phishing

O phishing engana usuários para que revelem dados sensíveis, como senhas e cartões. Normalmente ocorre por e-mails ou mensagens falsas.

Exemplo: E-mail falso do banco solicitando confirmação de dados.

💰 Ransomware

O ransomware criptografa arquivos da vítima e exige pagamento para liberação. Ele pode se espalhar rapidamente em redes vulneráveis.

Exemplo: WannaCry criptografando computadores com Windows desatualizado.

🔗 Ataques a APIs

Esses ataques exploram falhas de autenticação ou validação em APIs. Podem resultar em vazamento ou manipulação de dados.

Exemplo: Acessar dados de outros usuários alterando um ID na URL.

📄 Vulnerabilidades CVE

CVEs são falhas de segurança catalogadas publicamente. Atacantes exploram sistemas que não aplicam correções.

Exemplo: Explorar uma CVE conhecida em um servidor desatualizado.

🤖 Exploits Automatizados

Exploits automatizados utilizam scripts ou ferramentas para atacar múltiplos sistemas. Eles exploram vulnerabilidades sem interação humana.

Exemplo: Bot escaneando e atacando servidores vulneráveis automaticamente.

Ferramentas Utilizadas em Ataques e Testes de Segurança

Ferramenta Para que serve Como ajuda no ataque Medidas de defesa
Nmap Ferramenta de varredura de rede usada para identificar portas abertas e serviços em execução. Permite ao atacante descobrir serviços vulneráveis e pontos de entrada no sistema. Fechar portas desnecessárias, usar firewall e monitorar acessos suspeitos.
Burp Suite Ferramenta para testes de segurança em aplicações web. Intercepta e modifica requisições HTTP para explorar falhas como SQL Injection e XSS. Validar entradas, usar HTTPS e aplicar testes de segurança no desenvolvimento.
Metasploit Framework usado para explorar vulnerabilidades conhecidas. Automatiza ataques usando exploits prontos contra sistemas vulneráveis. Manter sistemas atualizados e aplicar correções de segurança.
Kali Linux Sistema operacional focado em testes de penetração e auditoria de segurança. Reúne diversas ferramentas que facilitam ataques e testes de invasão. Controle de acesso, monitoramento de rede e uso responsável das ferramentas.
Wireshark Ferramenta para captura e análise de tráfego de rede. Permite capturar dados sensíveis trafegando sem criptografia. Utilizar criptografia (HTTPS, VPN) e redes seguras.
Hydra Ferramenta usada para ataques de força bruta em serviços de login. Testa diversas combinações de usuário e senha automaticamente. Usar senhas fortes, MFA e bloqueio após tentativas falhas.
  • Aplicar updates
    Manter sistemas e softwares sempre atualizados reduz vulnerabilidades conhecidas. Atualizações frequentemente corrigem falhas de segurança exploradas por atacantes.
  • MFA (Autenticação de Dois Fatores)
    O MFA adiciona uma camada extra de segurança além da senha. Mesmo que a senha seja comprometida, o acesso ainda fica protegido.
  • Firewalls
    Firewalls controlam o tráfego de entrada e saída da rede. Eles ajudam a bloquear acessos não autorizados e ataques externos.
  • Senhas fortes
    Senhas devem conter letras, números e caracteres especiais. Isso dificulta ataques de força bruta e acessos indevidos.
  • Criptografia
    A criptografia protege dados sensíveis durante o armazenamento e a transmissão. Mesmo que os dados sejam interceptados, não poderão ser lidos facilmente.
  • Limitar portas abertas
    Apenas portas necessárias devem permanecer abertas no sistema. Isso reduz a superfície de ataque e possíveis invasões.
  • Validações no back-end
    As validações devem ocorrer no servidor para evitar dados maliciosos. Isso impede ataques como injeção de código e manipulação de dados.
  • Uso de Prepared Statements
    Prepared Statements evitam ataques de SQL Injection. Eles garantem que os dados do usuário sejam tratados de forma segura.
  • Backup frequente
    Backups regulares garantem a recuperação de dados em caso de falhas ou ataques. Eles são essenciais para a continuidade do negócio.
  • Políticas de acesso
    Definir permissões adequadas limita o acesso apenas a usuários autorizados. Isso reduz riscos de uso indevido e vazamento de informações.

Casos de Ataques Cibernéticos

Ataque do WannaCry (2017)

O que aconteceu:
O ataque do WannaCry foi um ransomware que se espalhou rapidamente em maio de 2017, afetando mais de 230.000 computadores em 150 países. Ele criptografava os arquivos dos sistemas infectados e exigia um resgate em Bitcoin para liberá-los. O ransomware se aproveitou de uma vulnerabilidade no sistema operacional Windows, conhecida como EternalBlue, que havia sido descoberta pela NSA (Agência de Segurança Nacional dos Estados Unidos) e, posteriormente, vazada pelo grupo Shadow Brokers.

Qual vulnerabilidade foi explorada:
O WannaCry explorou uma falha crítica no protocolo SMB (Server Message Block) do Windows, chamada EternalBlue. A vulnerabilidade permitia a execução remota de código, ou seja, um atacante podia invadir sistemas sem a necessidade de interação do usuário.

Impacto:
O impacto do ataque foi global, afetando hospitais, empresas e governos. Organizações como o NHS (Serviço Nacional de Saúde do Reino Unido) foram fortemente afetadas, com serviços interrompidos e dados comprometidos. O ataque causou milhões de dólares em prejuízos, além de interromper operações críticas em diversas indústrias.

Como poderia ter sido evitado:
O ataque poderia ter sido evitado caso as organizações tivessem aplicado as atualizações de segurança fornecidas pela Microsoft para corrigir a vulnerabilidade do EternalBlue. A Microsoft já havia liberado um patch para a falha meses antes do ataque, mas muitas empresas e usuários não haviam atualizado seus sistemas. Além disso, o uso de firewalls e a segmentação de rede ajudariam a minimizar o impacto do ataque.
